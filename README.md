# Code and Data

This directory contains the R scripts, analysis-ready input data, intermediate outputs, and generated figures used for the *Acropora millepora* chromatin-accessibility, gene-expression, and heat-stress analyses.

## Running the analyses

The scripts are numbered in the order of the main analysis workflow.

The current shared scripts assume that the R working directory is the directory **containing** `Code_and_data`, so that paths such as:

```r
./Code_and_data/Data_out/00_inputs/
```

resolve correctly.

The main workflow is:

```text
01  Build the RNA-seq count matrix
02  RNA-seq quality control
03  RNA-seq heat-stress differential-expression analysis
04  Dixon et al. heat-response module validation
05  RNA-seq GO enrichment
06  Build and annotate ATAC-seq consensus peaks
07  ATAC-seq quality control
08  ATAC-seq promoter GO enrichment
09  Integrate ATAC-seq and RNA-seq results
10  Analyze physiological heat-stress responses and generate the heat-response figure
```

Later scripts use files generated by earlier steps, so the scripts should generally be run in numerical order.

# Input data

## RNA-seq inputs

Directory:

```text
Data/00_inputs/RNAseq_counts/
```

This directory contains:

- 58 sample-level gene-count files (`*_gene_count.txt`)
- `tag_seq_meta_data.txt`

The count files are combined by `01_RNAseq_build_count_matrix.R`.

Genes with a summed read count of at least 10 across all samples are retained for downstream analysis. The resulting filtered RNA-seq dataset contains 19,649 genes.

# Analysis steps and outputs

## 01 — RNA-seq count matrix

Script:

```text
01_RNAseq_build_count_matrix.R
```

Output directory:

```text
Data/01_count_matrix/
```

This script combines the 58 sample-level gene-count files with the RNA-seq metadata, verifies sample correspondence, constructs the count matrix, and applies the minimum-count filter used for downstream analyses.

---

## 02 — RNA-seq quality control

Script:

```text
02_RNAseq_QC.R
```

Output directory:

```text
Data/02_QC/
```

This step performs exploratory RNA-seq quality control, including:

- variance-stabilizing transformation
- principal-component analysis
- variance-partition analysis

The variance-partition model evaluates contributions from genotype, acute heat stress, heat-stress assay day, extraction batch, and thermal history.

---

## 03 — RNA-seq heat-stress differential expression

Script:

```text
03_RNAseq_heat_stress_DESeq2.R
```

Output directory:

```text
Data/03_DESeq2/
```

The primary DESeq2 model is:

```r
~ genotype +
  stress_day +
  extraction_batch +
  thermal_history +
  heat_stress
```

The acute heat-stress contrast compares 36°C with the 24.5°C control condition.

Heat-responsive genes are defined using:

```text
adjusted p-value < 0.01
absolute log2 fold change > 2
```

This analysis identifies 2,611 heat-responsive genes.

---

## 04 — Dixon heat-response module validation

Script:

```text
04_RNAseq_Dixon_validation.R
```

Output directory:

```text
Data/04_Dixon_validation/
```

This analysis compares the heat-responsive genes identified in this study with the previously published heat-response module from Dixon et al. (2020).

The analysis includes:

- overlap between the Dixon red-module genes and the heat-responsive genes identified here
- Fisher's exact test for enrichment
- PCA based on represented Dixon red-module genes

The Dixon comparison data are derived from the published study and are not primary data generated in this project.

---

## 05 — RNA-seq GO enrichment

Script:

```text
05_RNAseq_GO_enrichment.R
```

Output directory:

```text
Data/05_GO_enrichment/
```

Gene Ontology enrichment of the RNA-seq heat-responsive genes is performed using `topGO`.

Multiple-testing correction is applied using the Benjamini-Hochberg method separately within each ontology.

Reported terms meet both of the following criteria:

```text
FDR < 0.05
at least 10 heat-responsive genes assigned to the term
```

## 06 — ATAC-seq consensus peaks

Script:

```text
06_ATAC_build_consensus_peaks.R
```

Output directory:

```text
Data/06_consensus_peaks/
```

This script:

- reads the ATAC-seq sample sheet
- constructs the DiffBind object
- counts reads overlapping binding sites
- generates consensus peaks represented in at least two of four samples
- calculates normalized accessibility values
- annotates consensus peaks relative to genomic features

The final consensus set contains 11,231 peaks.

## 08 — ATAC-seq GO enrichment

Script:

```text

```

Output directory:

```text
Data/08_GO_enrichment/
```

This analysis tests Gene Ontology enrichment among genes associated with accessible ATAC-seq promoters.

```text

```

## 09 — ATAC-seq/RNA-seq integration

Script:

```text
09_ATAC_RNA_integration.R
```

Output directory:

```text
Data/09_RNA_integration/
```

This script examines broad associations between baseline promoter accessibility and gene-expression characteristics.

The analyses include:

- promoter accessibility across gene-expression quintiles
- promoter accessibility across gene-expression variability quintiles
- overlap between accessible promoters and heat-responsive genes
- overlap between accessible promoters and Dixon red-module genes
- SNP density in promoters, distal regions and introns
- association between promoter accessibility and overall mean expression
- association between promoter accessibility and the magnitude of heat-induced expression change

The ATAC-seq and RNA-seq samples were independently sourced. These analyses therefore describe broad cross-dataset associations rather than matched accessibility-expression measurements within the same biological samples.

When multiple accessible promoter peaks are associated with the same gene, the promoter peak closest to the transcription start site is used for the gene-level integration analyses.

---

## 10 — Physiological heat-stress analysis

Script:

```text
10_physiology_heat_stress.R
```

Output directory:

```text
Data/10_heat_stress/
```

The physiological analyses include:

- Fv/Fm
- red-channel intensity
- log10-transformed glutathione reductase activity

For each metric, the final mixed-effects model is:

```r
trait ~ Heat.Stress.Treatment +
        Acc.Treatment +
        Heat.Stress.Day +
        (1 | Genotype)
```

Genotype is modeled as a random intercept.

Day 0 is excluded from these models because it preceded the thermal-history treatment.

The script saves the physiology model summaries and Type III ANOVA results and generates the physiological panels used in the heat-response figure.

Some analyses rely on reference or previously published resources that are not primary data generated in this study.

# Reproducibility notes

The scripts are intentionally organized as explicit sequential analysis steps rather than as a generalized pipeline.

`Data/00_inputs/` contains the analysis-ready data supplied with this repository. The numbered `Data_out/01_*` through `Data_out/10_*` directories contain intermediate and final products generated by the corresponding scripts.

Raw FASTQ files and ATAC-seq BAM files are deposited in the NCBI Sequence Read Archive under BioProject PRJNA1390403.

The repository is designed to reproduce the statistical analyses and figures beginning from the supplied analysis-ready count, peak, metadata, and physiology files. Upstream processing from raw sequencing reads is not reproduced within this directory.
